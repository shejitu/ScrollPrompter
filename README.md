# 滚动提示器（ScrollPrompter）

一款轻量的 Android 提词器 App：把文稿大字号铺满屏幕，按可调速度自动滚动，**支持语音跟随——你朗读时滚动、停顿自动暂停**。适合演讲、录课、直播、短视频口播提词。

> 作者：笑握刀锋 · just for musi！
>
> 当前版本：**v1.8** ｜ 体积仅约 6 MB ｜ 纯离线，不联网、不收集任何数据

## 📲 安装步骤

1. 把 APK 传到手机/平板（微信文件传输助手、数据线、网盘均可）
2. 在设备上点击 APK 文件
3. 系统提示「未知来源应用」时，选择 **允许 / 仍要安装**（各品牌入口略有不同，一般会自动引导）
4. 安装完成，打开「滚动提示器」

> ⚠️ 升级新版一般可直接覆盖安装；若提示「安装失败/签名冲突」，先卸载旧版再装（注意：卸载会清掉保存的文稿与历史，建议先在编辑框里把内容复制出来）。
>
> ⚠️ 本 App 未上架应用商店，属正常现象，请放心安装（仅供个人学习交流使用）。

## 📖 使用指南

### 基本流程

1. 打开 App，稍等 2 秒闪屏（just for musi！）自动进入主界面
2. 点底部 **文稿** 按钮 → 弹出编辑框 → 粘贴你的文稿 → 点 **保存**
3. 点 **▶ 播放**，文稿自动滚动；再点一下暂停
4. 播放中点文字区：**左半屏后退、右半屏前进**（快速回到读错的位置）
5. 点 **⚙ 设置** 调整字号、速度、颜色、亮度等

### 编辑文稿（弹出的固定对话框）

| 按钮 | 作用 |
|---|---|
| **清空** | 一键清掉文本框内容，方便直接粘贴新稿（点「保存」后才真正生效） |
| **取消** | 关闭不保存 |
| **保存** | 保存文稿并立即显示在提词区 |
| **历史** | 每次保存自动记入历史（最多 30 条），标签 = 时间 + 内容前 8 字，点任意一条填回输入框 |

文稿很长也不用担心：编辑框固定大小，超长内容在框内下拉滚动，四个按钮始终可见。

### 设置面板

- **字体大小**：滑条（24~90sp）+ 输入框直输（12~200sp），双向联动
- **滚动速度**：慢 ↔ 快，极速档自动加速（最快约为常规档 3.7 倍）
- **文字颜色**：白 / 黄 / 绿 / 青 / 橙 / 粉 六色可选，会记住你的选择
- **屏幕亮度**：自动 / 低 / 中 / 高 四档循环切换（提词时调暗更省电护眼）
- **跟随灵敏度**：语音跟随的判定灵敏度（×2.0 最灵敏 ~ ×6.0 最迟钝，默认 ×3.0）
- **跟随屏幕**：开（默认）= 横屏竖屏控制栏都自动贴底；关 = 播放时控制栏自动隐藏（沉浸读稿），点屏幕呼出

### 🎙 语音跟随（招牌功能）

点底部 **麦克风** 按钮（首次使用需允许麦克风权限）：

- **你朗读 → 文稿自动滚动**
- **你停顿（约 1.5 秒）→ 自动暂停**
- **再次开口 → 继续滚动**
- 滚到文末自动停住；点左半屏回跳后自动恢复跟随
- 再点一下麦克风即退出跟随

纯本机音量检测实现，**完全离线**，不依赖任何手机的语音服务，所有品牌设备通用。朗读时若频繁误停/该停不停，到设置里调「跟随灵敏度」即可。

## ❓ 常见问题

**Q：安装时提示危险/未知来源？**
A：因为 APK 没有上架商店，安卓对所有侧载应用都会这样提示，允许即可。

**Q：语音跟随没有反应？**
A：① 检查是否已授予麦克风权限；② 环境太吵会把噪声底抬高，适当调高灵敏度倍率（×4~×6）；③ 正常音量朗读即可，不必凑近麦克风。

**Q：滚动太快/太慢？**
A：设置 → 滚动速度滑条；需要极快速度滑到最右端（极速档会自动加倍步长）。

**Q：更新版本后文稿和历史会丢吗？**
A：直接覆盖安装不会丢；卸载重装会清空（ SharedPreferences 随应用删除）。
